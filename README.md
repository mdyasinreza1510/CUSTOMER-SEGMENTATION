# 🛍️ Customer Segmentation using Machine Learning

A Machine Learning web application that segments customers into different groups based on their purchasing behavior using the **K-Means Clustering** algorithm. This project helps businesses understand customer patterns and create targeted marketing strategies.

---

# 📌 Project Overview

Customer segmentation is the process of dividing customers into different groups based on similar characteristics.

In this project, customers are grouped using **K-Means Clustering** based on:

- Age
- Income
- Total Spending
- Total Purchases

The trained model predicts which customer segment a new customer belongs to.

---

# 🎯 Problem Statement

Businesses often have thousands of customers with different purchasing behaviors.

Instead of treating every customer the same, companies can divide customers into meaningful segments to:

- Improve marketing campaigns
- Increase customer retention
- Recommend suitable products
- Understand customer behavior
- Increase business revenue
